# Game Community Project
Sebuah website yang dibuat untuk membantu para gamers di luar sana untuk bisa saling berkomunikasi antar player satu sama lain dan bisa berbagi ilmu, cerita, dan pengalaman bermain game, terutama untuk game kompetitif, bukan hanya tempat perkumpulam para komunitas biasa, tetapi juga merupakan tempat dimana player baru bisa belajar dari para player veteran
